# NotionImages

Welcome to NotionImages! This project aims to provide users with enhanced image management and accessibility within Notion.

## Features
- **Image Uploading**: Seamlessly upload images into your Notion workspace.
- **Image Sharing**: Share and collaborate on images with your team.

## Roadmap
- **Maps**: Integration of interactive maps to enhance visual storytelling and data representation.
- **QR Scanner**: Feature to easily scan and upload images from QR codes.
- **Enhanced Authentication**: Improving security protocols ensuring user data protection and privacy.

## Installation
To get started, clone this repository and install the required dependencies:

```bash
git clone https://github.com/JuanjoMedina23/NotionImages.git
cd NotionImages
```
